# ARVMex: A web application for obtaining acoustic reference values for forensic studies in Spanish

# ABSTRACT

Forensic speech experts using the auditory-acoustic-phonetic approach face different challenges when analyzing recordings collected under different technical conditions, as these conditions can affect acoustic measurements. This study presents ARVMex, an open-access web application that provides acoustic reference values for Mexican Spanish and characterizes variation due to technical conditions. ARVMex generates statistics and visualizations based on user-selected attributes, including speaker sex, vowel, acoustic parameter, and technical condition: face-to-face interviews and telephone-bandwidth-filtered recordings. Results showed that, for fundamental frequency (f0), the overall mean across vowels adequately represented vowel-specific values under the interview condition, whereas vowel-specific reference values were appropriate under the telephone-bandwidth condition. For vowel formants, the findings support establishing reference values by vowel, sex, and technical condition, given the differences observed across vowels and recording conditions. ARVMex provides forensic voice comparison experts with an accessible resource for exploring acoustic reference values and as-sessing the effects of technical conditions on acoustic measurements.
